# Mischief

This repository contains the [VS Code extension](vscode-extension/README.md) and the [macOS app prototype](macos/README.md). See the [macOS plan](docs/macos-app-plan.md).

Development requires pnpm:

```sh
pnpm install
pnpm check
```

The extension can also be built and packaged from `vscode-extension/`. Open this repository in VS Code and press F5 to launch its extension development host.
