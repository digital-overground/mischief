Problem

The pending change makes the Skills popup show generic ACP commands, but classification, labels, and prompt insertion now split across ACP translation, picker grouping, and slash autocomplete; the same Agent command can follow different rules in each path.

Solution

Deepen Thread command handling so one place owns Agent-command meaning and insertion behavior; keep inline suggestions and the browse popup as distinct presentation choices.

Benefits

  • Locality: command rules stay together
  • Leverage: both entry points share behavior
  • Tests verify one command path
  • UI names match Agent commands

Top recommendation

Deepen Thread command handling

The pending change expands the popup from skill browsing to generic Agent commands, bringing the split command semantics directly into scope. Keep both entry points unless their distinct browse and prefix behaviors prove redundant.
