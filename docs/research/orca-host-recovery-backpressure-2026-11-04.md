# How Orca handles stale endpoints, slow clients, and launch races

Inspected local checkout `/Users/kyle/Projects/_external/orca` at [`9f8515d`](https://github.com/stablyai/orca/tree/9f8515de57cd6934358766b69f5f15e71ee7008b) on 2026-11-04. The terminal daemon below is **not** Orca's whole application runtime: desktop Electron or headless `orcad` also hosts application/Agent state; `orcad` has its own [per-data-root instance lock](https://github.com/stablyai/orca/blob/9f8515de57cd6934358766b69f5f15e71ee7008b/src/main/orcad/orcad-instance-lock.ts#L119-L191).

1. **Stale socket, even without a PID/lock record.** A candidate daemon first listens on a private random socket name, then attempts to hard-link that live socket into the canonical name. If occupied, it probes the canonical socket with a 500 ms timeout. Only `ECONNREFUSED` or a missing entry proves the old listener dead; connected or unknown refuses takeover. It checks the directory entry's device/inode around the probe, probes again, atomically renames the candidate over a proven-dead entry, and verifies the candidate now holds the name. The socket itself, not a separate PID file, is the source of truth for this decision ([publisher](https://github.com/stablyai/orca/blob/9f8515de57cd6934358766b69f5f15e71ee7008b/src/main/daemon/daemon-endpoint-ownership.ts#L1-L171), [probe](https://github.com/stablyai/orca/blob/9f8515de57cd6934358766b69f5f15e71ee7008b/src/main/daemon/daemon-endpoint-probe.ts#L1-L61), [lifecycle](https://github.com/stablyai/orca/blob/9f8515de57cd6934358766b69f5f15e71ee7008b/src/main/daemon/daemon-endpoint-lifecycle.ts#L35-L88)). Unlike Mischief's current lock-first approach, this recovers a dead socket for which there is **no lock file**.
2. **Slow client.** Orca does not blindly write every stream frame to a stalled client. Its terminal stream holds writes when the socket backlog reaches 128 KiB, resumes on `drain`, accounts for pending bytes, pauses foreground producers at high-water marks, and trims droppable background output to a bounded tail while retaining a gap marker ([batcher](https://github.com/stablyai/orca/blob/9f8515de57cd6934358766b69f5f15e71ee7008b/src/main/daemon/daemon-stream-data-batcher.ts#L26-L125), [drain hook](https://github.com/stablyai/orca/blob/9f8515de57cd6934358766b69f5f15e71ee7008b/src/main/daemon/daemon-client-connections.ts#L256-L278), [backpressure](https://github.com/stablyai/orca/blob/9f8515de57cd6934358766b69f5f15e71ee7008b/src/main/daemon/daemon-stream-backpressure.ts#L1-L137), [tail dropping](https://github.com/stablyai/orca/blob/9f8515de57cd6934358766b69f5f15e71ee7008b/src/main/daemon/daemon-stream-keep-tail-drop.ts#L1-L137)). Remote WebSocket replies use a bounded FIFO queue that closes/resyncs on overflow ([queue](https://github.com/stablyai/orca/blob/9f8515de57cd6934358766b69f5f15e71ee7008b/src/shared/ws-outbound-backpressure-queue.ts#L1-L62), [remote admission](https://github.com/stablyai/orca/blob/9f8515de57cd6934358766b69f5f15e71ee7008b/src/main/runtime/rpc/mobile-e2ee-outbound-admission.ts#L50-L77)). For Mischief's **replaceable library snapshots**, a small pending-output cap plus disconnect/resnapshot is enough; copying PTY byte-order, producer-pausing, and gap machinery would be unnecessary.
3. **Concurrent launch/recovery.** The private-listener + canonical-name claim gives one winner. A losing candidate sees an occupied or changed name and refuses to serve; the launcher can adopt the authenticated winner ([publisher](https://github.com/stablyai/orca/blob/9f8515de57cd6934358766b69f5f15e71ee7008b/src/main/daemon/daemon-endpoint-ownership.ts#L38-L84), [adoption test](https://github.com/stablyai/orca/blob/9f8515de57cd6934358766b69f5f15e71ee7008b/src/main/daemon/daemon-init-endpoint-adoption.test.ts#L124-L159)). Tests inject races during probing and replacement, verify a live incumbent is untouched, verify a stale socket can be replaced, and check that the losing listener never serves ([publication tests](https://github.com/stablyai/orca/blob/9f8515de57cd6934358766b69f5f15e71ee7008b/src/main/daemon/daemon-endpoint-publish.test.ts#L75-L154), [stale published endpoint](https://github.com/stablyai/orca/blob/9f8515de57cd6934358766b69f5f15e71ee7008b/src/main/daemon/daemon-endpoint-publish.test.ts#L641-L675)).
