# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the Linear labels used by team `MIS`.

| Label in mattpocock/skills | Label in Linear | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or verification |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a canonical triage role, apply the corresponding Linear label.
